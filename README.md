# Numerical Validation of Controlled-Quantile Gradient and Hessian Formulas

A Python repository implementing six numerical experiments that validate the
analytical gradient and Hessian formulae for the portfolio quantile function
q_α(u) = VaR_α(u⊤X) under multivariate lognormal distributions.

The experiments test Theorem 1.1 and its corollaries: that the quantile
gradient equals the conditional mean on the quantile level set, that the
quantile Hessian in the linear case is entirely generated by a transport term
involving the pulled-back surface measure μ_y on S₁, and that quantile curves
exhibit universal asymptotic shapes in both interior and corner regimes.

## Mathematical Setup

- **X = exp(Z)**, Z ~ N(μ, A), where **B = A⁻¹** (precision-like matrix).
- **Portfolio payoff**: Y = u⊤X (linear, u on the 2D simplex u = (t, 1−t)).
- **Column sums**: bᵢ = Σⱼ Bⱼᵢ, β = Σᵢ bᵢ.
- **Quantile gradient (Theorem 1.1)**: ∂q_α/∂u = E[X | u⊤X = q_α(u)].
- **Surface measure μ_y** on S₁ = {x>0 : u⊤x=1}: density ∝ exp(−w_y(x)),
  where w_y(x) = log(y)·a(x) + φ_X(x), a(x) = Σᵢ bᵢ log xᵢ.
- **Universal interior shape**: q₀(t) = exp((1/β)[b₁ log(βt/b₁) + b₂ log(β(1−t)/b₂)]).

## Experiments

| ID | Title | Key Metric |
|----|-------|------------|
| Exp 1 | Gradient & Hessian validation | Gradient correlation ≥ 0.99 (left tail); homogeneity error = 0 |
| Exp 2 | Left-tail concavity & universal shape | Shape error → 0 as α → 0; optimizer → b₁/β |
| Exp 3 | Corner-regime asymptotics (S3) | Linear shape R² → 1.0; optimizer collapse to corners |
| Exp 4 | Mass-flow & critical-point diagnostics | Transport sign matches curvature; critical-point count transitions |
| Exp 5 | Simplex optimizer convergence | Optimizer error → 0; A-formula matches b/β to machine precision |
| Exp 6 | Subadditivity diagnostics | Δ_α ≤ 0 for interior regimes; Δ_α > 0 for corner S3 |

## Installation

```bash
# Python ≥ 3.10; all packages already present in the provided environment
pip install numpy scipy pandas matplotlib
```

No API keys or external data sources are required — all experiments use
synthetic multivariate lognormal samples generated in-process.

## Usage

```bash
# Generate data (optional — experiments generate samples inline)
python -m data.generate_data --n_samples 100000 --output_dir data/

# Run individual experiments
python -m exp.exp1_gradient_hessian
python -m exp.exp2_left_tail_concavity
python -m exp.exp3_corner_regime
python -m exp.exp4_mass_flow
python -m exp.exp5_optimizer
python -m exp.exp6_subadditivity

# Run test suite
python -m pytest tests/ -q
```

All results (figures and CSVs) are written to `results/`.

## Testing

```bash
python -m pytest tests/ -v
```

The test suite covers: scenario construction, SPD validation, lognormal
simulation, empirical quantiles, finite differences, S₁ parameterisation,
quadrature normalisation, μ_y moments, and curvature-sign diagnostics.
